# Instagram portfolio thumbnails

Add one cover image per Instagram item in this folder and set the card data-thumb to its relative path. Name each file with its reel or post ID, for example:

- Dc0zx6WANxi.webp
- DdQ0focFEYo.jpg

Use the original content aspect ratio where possible: vertical for reels, portrait for carousels, and landscape for widescreen posts. WebP and JPEG files are supported. YouTube covers load from YouTube using the video ID.
